## Dataset

Dataset yang digunakan dalam penelitian ini merupakan citra daun mangga
yang diperoleh dari Kaggle. Dataset terdiri dari dataset asli dan dataset
hasil augmentasi yang digunakan dalam proses penelitian.

### Sumber Dataset

**1. Dataset Asli**

Mango Leaf Disease Dataset oleh Aryashah2k:

https://www.kaggle.com/datasets/aryashah2k/mango-leaf-disease-dataset

Dataset ini digunakan sebagai sumber dataset asli sebelum dilakukan
proses augmentasi.

**2. Dataset Augmented**

Mango Leaf Disease Dataset oleh Shajedur:

https://www.kaggle.com/datasets/shajedur0/mango-leaf-disease-dataset

Dataset ini menyediakan citra hasil augmentasi yang digunakan dalam
penelitian.

Karena ukuran dataset cukup besar, file citra tidak disertakan langsung
dalam repository GitHub. Dataset dapat diunduh melalui sumber Kaggle
di atas.
