# Klasifikasi Penyakit Die Back pada Daun Mangga

Project Computer Vision dan Machine Learning untuk klasifikasi daun mangga sehat dan daun yang terinfeksi penyakit Die Back.

## Metode

### Machine Learning
- SVM
- Random Forest
- Naive Bayes
- Decision Tree

### Deep Learning
- CNN
- MobileNetV2
- ResNet50

## Teknologi
- Python
- OpenCV
- Pandas
- NumPy
- Scikit-learn
- TensorFlow/Keras
- Matplotlib
